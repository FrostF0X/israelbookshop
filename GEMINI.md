# General Guidelines for AI Agents

1. **Commit and Push Requirements:** You must commit and push your changes directly to the main branch at all times after completing a significant task. Do not use branches.
2. **Reading Context:** All reports are produced by GitHub CI. You must read the context from the last Lighthouse report at `https://frostf0x.github.io/israelbookshop/lighthouse-report.html` before every agent conversation.
